## Cu acuzativul

Aproape toate prepozițiile.

la, în, pe, cu, de, din, pentru, spre, către, până, fără, despre, prin, peste, sub, lângă, între, printre, dintre, după.

(*ca* și *decât* introduc tot acuzativul, dar sunt conjuncții comparative, nu prepoziții. Pentru *într-un*, *dintr-un*, *printr-un*, vezi *Contragerile*, mai jos.)

După o prepoziție simplă, substantivul rămâne de obicei **nearticulat**:

- *merg **la școală***, *sunt **în oraș***, *plec **la muncă***
- dar: *merg **la școala** din colț* (determinat)
- excepție, **cu**: *plec **cu trenul***, *scriu **cu creionul***

## Cu genitivul

asupra, contra, împotriva, deasupra, dedesubtul, înaintea, înapoia, împrejurul, în jurul, în fața, în spatele, în locul, de-a lungul, în urma.

Substantivul stă **articulat**: *deasupra **mesei***, *în fața **casei***, *împotriva **legii***.

> Cu pronumele personal, aceste prepoziții cer forma **posesivă**, nu genitivul: *în fața **mea***, *asupra **noastră***, *împotriva **lor***.

## Cu dativul

datorită, grație, mulțumită, conform, potrivit, contrar, asemenea, aidoma.

*datorită **prietenilor***, *conform **legii***, *contrar **așteptărilor***.

> **datorită** are sens pozitiv, **din cauza** (+ genitiv) are sens negativ: *datorită ție am reușit* / *din cauza ta am pierdut trenul*.

## Prepoziții cu mai multe valori

| | |
|---|---|
| **de** — materie | masă **de** lemn |
| **de** — conținut | pahar **de** apă |
| **de** — agent, la pasiv | scris **de** el |
| **de** — supin | ceva **de** făcut |
| **la** — destinație | merg **la** gară |
| **la** — dativ colocvial | dau **la** copii |
| **pe** — suprafață | **pe** masă |
| **pe** — complement direct | îl văd **pe** Ion |
| **în** — interior, timp | **în** casă, **în** două zile |
| **din** — proveniență | sunt **din** Cluj |
| **cu** — instrument, însoțire | **cu** mașina, **cu** el |

## Contrageri

Prepoziția fuzionează cu articolul nehotărât:

| | |
|---|---|
| în + un / o | **într-un**, **într-o** |
| din + un / o | **dintr-un**, **dintr-o** |
| prin + un / o | **printr-un**, **printr-o** |
| pe + un / o | **pe un**, **pe o** *(nu fuzionează)* |
