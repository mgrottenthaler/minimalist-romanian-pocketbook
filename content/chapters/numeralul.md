## Cardinalele

| | | | |
|---|---|---|---|
| 0 zero | 10 zece | 20 douăzeci | 100 o sută |
| 1 unu / una | 11 unsprezece | 21 douăzeci și unu | 200 două sute |
| 2 doi / două | 12 doisprezece / douăsprezece | 30 treizeci | 1000 o mie |
| 3 trei | 13 treisprezece | 40 patruzeci | 2000 două mii |
| 4 patru | 14 paisprezece | 50 cincizeci | 10 000 zece mii |
| 5 cinci | 15 cincisprezece | 60 șaizeci | 1 000 000 un milion |
| 6 șase | 16 șaisprezece | 70 șaptezeci | |
| 7 șapte | 17 șaptesprezece | 80 optzeci | |
| 8 opt | 18 optsprezece | 90 nouăzeci | |
| 9 nouă | 19 nouăsprezece | | |

Se acordă în gen numai **unu / una** și **doi / două**, inclusiv în compuse: *douăzeci și una de fete*, *treizeci și doi de ani*.

> Atenție la formele scurtate: **paisprezece** (nu *patrusprezece*), **șaisprezece**, **șaizeci**.

## Legătura cu substantivul: `de`

Substantivul se leagă prin **de**, cu excepția numerelor ale căror **ultime două cifre** sunt 1–19. Contează grupul final, nu ultima cifră: *douăzeci și unu* se termină în *1*, dar are nevoie de **de**.

| Fără `de` | Cu `de` |
|---|---|
| cinci lei | douăzeci **de** lei |
| nouăsprezece ani | douăzeci și cinci **de** ani |
| o sută cinci lei | o sută **de** lei |
| două mii optsprezece lei | douăzeci și unu **de** ani |

## Ordinalele

**al** + cardinal + **-lea** (m./n.), **a** + cardinal + **-a** (f.).

| | Masculin | Feminin |
|---|---|---|
| 1 | primul, întâiul | prima, întâia |
| 2 | al doilea | a doua |
| 3 | al treilea | a treia |
| 4 | al patrulea | a patra |
| 5 | al cincilea | a cincea |
| 10 | al zecelea | a zecea |
| 20 | al douăzecilea | a douăzecea |
| 100 | al o sutălea | a o suta |

## Alte numerale

| Tip | Forme |
|---|---|
| colectiv | amândoi / amândouă, ambii / ambele, tustrei |
| fracționar | o jumătate, un sfert, o treime, două cincimi |
| multiplicativ | dublu, triplu, îndoit, întreit |
| distributiv | câte doi, câte trei, câte unul |
| adverbial | o dată, de două ori, de trei ori |

## Ora și data

| | |
|---|---|
| Cât e ceasul? | E ora **unu**. E **două**. E **douăsprezece**. |
| :15 | două și un sfert / două și cincisprezece |
| :30 | două și jumătate |
| :45 | trei fără un sfert / două și patruzeci și cinci |
| data, ziua 1 | **întâi** ianuarie |
| data, restul | **doi** ianuarie, **douăzeci** martie |
| anul | 2026 = două mii douăzeci și șase |

Zecimalele se citesc cu **virgulă**: *0,5* = zero virgulă cinci. Miile se separă prin spațiu sau punct: *10 000*, *10.000*.
