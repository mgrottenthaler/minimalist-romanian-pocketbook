## Imperfectul

Două seturi de terminații, după conjugare.

| | I și IV în -î | II, III, IV în -i |
|---|---|---|
| | a cânta | a merge |
| eu | cânt**am** | merg**eam** |
| tu | cânt**ai** | merg**eai** |
| el / ea | cânt**a** | merg**ea** |
| noi | cânt**am** | merg**eam** |
| voi | cânt**ați** | merg**eați** |
| ei / ele | cânt**au** | merg**eau** |

La fel: *coboram, hotăram* (ca *cântam*); *vedeam, dormeam, citeam* (ca *mergeam*).

**a fi**: eram, erai, era, eram, erați, erau.

> Persoana 1 singular și 1 plural au aceeași formă: *cântam* = *eu* sau *noi*. Contextul decide.

Folosire: acțiune neterminată sau repetată în trecut, descriere, fundal. *Când eram mic, mergeam des la bunici.*

## Perfectul compus

Auxiliarul **a avea** în forme scurte + participiul, invariabil.

| | | |
|---|---|---|
| eu | **am** cântat | |
| tu | **ai** cântat | |
| el / ea | **a** cântat | *(nu „are”)* |
| noi | **am** cântat | |
| voi | **ați** cântat | |
| ei / ele | **au** cântat | |

Este timpul trecut obișnuit al limbii vorbite: acoperă și *I sang*, și *I have sung*.

| Cu clitice | |
|---|---|
| **l-am** văzut | acuzativ masculin |
| **i-am** dat | dativ |
| **ne-a** spus | dativ / acuzativ plural |
| am văzut-**o** | *o* stă întotdeauna după participiu |
| **nu** l-am văzut | negația precedă tot grupul |

## Mai-mult-ca-perfectul

O singură formă, fără auxiliar.

| | a cânta | a merge |
|---|---|---|
| eu | cânta**sem** | merse**sem** |
| tu | cânta**seși** | merse**seși** |
| el / ea | cânta**se** | merse**se** |
| noi | cânta**serăm** | merse**serăm** |
| voi | cânta**serăți** | merse**serăți** |
| ei / ele | cânta**seră** | merse**seră** |

Radicalul se obține din participiu:

| Participiu în | Se face | Exemple |
|---|---|---|
| **-t** | se scoate *-t*, se adaugă *-sem* | cânta**t** → cântasem; văzu**t** → văzusem; făcu**t** → făcusem; dormi**t** → dormisem |
| **-s** | se adaugă *-esem* | mer**s** → mersesem; scri**s** → scrisesem; pu**s** → pusesem |

**a fi**: fusesem, fuseseși, fusese, fuseserăm, fuseserăți, fuseseră.

Folosire: acțiune anterioară altei acțiuni trecute. *Când am ajuns, plecaseră deja.*
