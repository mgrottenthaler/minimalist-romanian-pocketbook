## Topica

Ordinea neutră este **subiect – verb – complement**, dar este liberă: elementul pus la început sau la sfârșit primește accentul.

- *Ion a citit cartea.* — neutru
- *Cartea a citit-o Ion.* — tema este cartea (observă dublarea clitică)
- *A venit Ion.* — subiect nou, informație nouă

Subiectul se omite când reiese din desinență: *Vin.* *Ai înțeles?*

## Negația

**nu** stă înaintea verbului și se contrage cu cliticele: *nu-l văd*, *nu-mi place*, *nu ne-a spus*.

Negația este **obligatoriu dublă**: cuvintele negative cer *nu* la verb.

- ***Nu** văd **nimic**.*
- ***Nu** vine **nimeni**.*
- ***Nu** merg **niciodată nicăieri** cu **nimeni**.*

## Întrebarea

Fără inversiune și fără auxiliar. Întrebarea totală se marchează numai prin **intonație**:

- *Vii mâine?* — *Vii mâine.*

Întrebarea parțială începe cu cuvântul interogativ: **cine, ce, care, cât, unde, când, cum, de ce, cu cine, pe cine**.

Răspunsuri: **da**, **nu**, și **ba da / ba nu** pentru a contrazice o întrebare negativă — *Nu vii? — **Ba da**, vin.*

## Complementul direct cu *pe* {.may-break}

**pe** este obligatoriu înaintea complementului direct care denumește o **persoană determinată**, precum și înaintea pronumelor.

| Cu *pe* | Fără *pe* |
|---|---|
| Îl văd **pe** Ion. | Văd o fată. |
| O cunosc **pe** sora ta. | Caut un medic. |
| **Pe cine** aștepți? | Ce aștepți? |
| Nu cunosc **pe** nimeni. | Citesc cartea. |

## Dublarea clitică

Când complementul stă înaintea verbului, sau când este introdus cu *pe*, verbul primește obligatoriu și pronumele neaccentuat.

| | |
|---|---|
| complement direct antepus | Cartea **o** citesc mâine. |
| complement direct cu *pe* | **Îl** văd **pe** Ion. |
| complement indirect | **Îi** dau **lui Ion** cartea. |
| complement indirect antepus | **Lui Ion îi** dau cartea. |

## Conjuncții

| Coordonare | |
|---|---|
| copulative | și, nici |
| adversative | dar, însă, ci, iar |
| disjunctive | sau, ori, fie |
| conclusive | deci, așadar, prin urmare |

| Subordonare | |
|---|---|
| completive | **că** (indicativ), **să** (conjunctiv), **dacă** (interogativ indirect) |
| cauzale | pentru că, fiindcă, deoarece, întrucât |
| finale | ca să, pentru ca să |
| concesive | deși, cu toate că, chiar dacă |
| consecutive | încât, așa încât |
| temporale | când, până când, îndată ce, după ce |
| condiționale | dacă, în caz că |

> **că** sau **să**? *că* introduce o constatare și cere indicativul (*Știu **că** vine*); *să* introduce o voință, o posibilitate sau un scop și cere conjunctivul (*Vreau **să** vină*). Interogativa indirectă cere *dacă*: *Nu știu **dacă** vine.*
