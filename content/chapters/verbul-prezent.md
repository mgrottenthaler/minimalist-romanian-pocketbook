## Cele patru conjugări

Se recunosc după terminația infinitivului.

| | Terminație | Model |
|---|---|---|
| I | **-a** | a cânta, a lucra |
| II | **-ea** | a vedea, a putea |
| III | **-e** | a merge, a face |
| IV | **-i**, **-î** | a dormi, a citi, a coborî |

## Conjugarea I

| | a cânta | a lucra (sufix **-ez**) |
|---|---|---|
| eu | cânt | lucr**ez** |
| tu | cânț**i** | lucr**ez**i |
| el / ea | cânt**ă** | lucr**eaz**ă |
| noi | cânt**ăm** | lucr**ăm** |
| voi | cânt**ați** | lucr**ați** |
| ei / ele | cânt**ă** | lucr**eaz**ă |

## Conjugările II și III

| | a vedea | a merge |
|---|---|---|
| eu | văd | merg |
| tu | vez**i** | merg**i** |
| el / ea | ved**e** | merg**e** |
| noi | ved**em** | merg**em** |
| voi | ved**eți** | merg**eți** |
| ei / ele | văd | merg |

La aceste două conjugări, **persoana 3 plural este identică cu persoana 1 singular**.

## Conjugarea IV

| | a dormi | a citi (**-esc**) | a coborî | a hotărî (**-ăsc**) |
|---|---|---|---|---|
| eu | dorm | cit**esc** | cobor | hotăr**ăsc** |
| tu | dorm**i** | cit**ești** | cobor**i** | hotăr**ăști** |
| el / ea | doarm**e** | cit**ește** | coboar**ă** | hotăr**ăște** |
| noi | dorm**im** | cit**im** | cobor**âm** | hotăr**âm** |
| voi | dorm**iți** | cit**iți** | cobor**âți** | hotăr**âți** |
| ei / ele | dorm | cit**esc** | coboar**ă** | hotăr**ăsc** |

## Sufixele -ez, -esc, -ăsc

Nu există regulă: sufixul se învață odată cu verbul.

| Sufix | Apare la | Exemple |
|---|---|---|
| **-ez** | conjugarea I | a lucra, a dansa, a nota, a forma |
| **-esc** | conjugarea IV în -i | a citi, a vorbi, a găsi, a iubi |
| **-ăsc** | conjugarea IV în -î | a hotărî, a urî |

Sufixul apare numai la persoanele 1, 2, 3 singular și 3 plural. La *noi* și *voi* dispare întotdeauna: *lucrez* → *lucrăm*; *citesc* → *citim*.

## Alternanțe în radical

Apar la persoanele unde accentul cade pe radical.

| | Exemplu |
|---|---|
| o → oa | dorm → d**oa**rme, zbor → zb**oa**ră |
| e → ea | plec → pl**ea**că, leg → l**ea**gă |
| a → ă | (la *noi*, *voi*) cânt → c**â**ntăm |
| d → z | vă**d** → ve**z**i |
| t → ț | cân**t** → cân**ț**i, ara**t** → ara**ț**i |
| s → ș | co**s** → co**ș**i |
| st → șt | gu**st** → gu**șt**i |
| c → ci | ple**c** → ple**ci**, du**c** → du**ci** |
| g → gi | mer**g** → mer**gi**, le**g** → le**gi** |

## Ce acoperă prezentul

- prezentul propriu-zis: *Acum lucrez.*
- viitorul apropiat, cu marcă de timp: *Mâine plec la Cluj.*
- acțiuni generale și obiceiuri: *Beau cafea dimineața.*

Româna nu are aspect continuu: *lucrez* traduce și *I work*, și *I am working*.
