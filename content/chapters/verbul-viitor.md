title: "Verbul: viitorul"
weight: 80
---

Româna are două forme de viitor active: una scrisă, una vorbită.

## 1. Viitorul literar

Auxiliar + **infinitivul fără *a***.

| | |
|---|---|
| eu | **voi** cânta |
| tu | **vei** cânta |
| el / ea | **va** cânta |
| noi | **vom** cânta |
| voi | **veți** cânta |
| ei / ele | **vor** cânta |

Registru: scris, presă, texte oficiale, discurs formal.

## 2. Viitorul curent: `o să` + conjunctiv

**o să** este invariabil; se schimbă numai verbul.

| | |
|---|---|
| eu | o să cânt |
| tu | o să cânți |
| el / ea | o să cânt**e** |
| noi | o să cântăm |
| voi | o să cântați |
| ei / ele | o să cânt**e** |

Registru: limba vorbită standard. **Este forma pe care o vei folosi și o vei auzi cel mai des.**

## Prezentul cu valoare de viitor

Cea mai simplă soluție, și foarte frecventă, este prezentul cu o marcă de timp:

- *Mâine **plec** la Cluj.*
- *Săptămâna viitoare **avem** examen.*

> Viitorul cu *am să*, viitorul popular (*oi cânta*) și viitorul anterior (*voi fi cântat*) nu sunt tratate în această carte: vezi ultimul capitol.
