---
title: "Verbul: viitorul"
weight: 80
---

Româna are patru construcții de viitor, cu același înțeles, dar cu registre diferite.

## 1. Viitorul literar

Auxiliar + **infinitivul fără *a***.

| | |
|---|---|
| eu | **voi** cânta |
| tu | **vei** cânta |
| el / ea | **va** cânta |
| noi | **vom** cânta |
| voi | **veți** cânta |
| ei / ele | **vor** cânta |

Registru: scris, presă, texte oficiale, discurs formal.

## 2. Viitorul curent: `o să` + conjunctiv

**o să** este invariabil; se schimbă numai verbul.

| | |
|---|---|
| eu | o să cânt |
| tu | o să cânți |
| el / ea | o să cânt**e** |
| noi | o să cântăm |
| voi | o să cântați |
| ei / ele | o să cânt**e** |

Registru: limba vorbită standard. **Este forma pe care o vei folosi și o vei auzi cel mai des.**

## 3. Viitorul familiar: `a avea` + conjunctiv

| | |
|---|---|
| eu | **am** să cânt |
| tu | **ai** să cânți |
| el / ea | **are** să cânte |
| noi | **avem** să cântăm |
| voi | **aveți** să cântați |
| ei / ele | **au** să cânte |

Registru: conversație familiară; nuanță de intenție sau de obligație asumată.

## 4. Viitorul popular

**oi, ăi / ei, o, om, ăți / eți, or** + infinitiv: *oi cânta*, *o veni*.

Registru: popular și regional. Adaugă adesea o nuanță de îndoială: *O veni el cândva.* Se recunoaște, nu se folosește în scris.

## Prezentul cu valoare de viitor

Cea mai simplă soluție, și foarte frecventă, este prezentul cu o marcă de timp:

- *Mâine **plec** la Cluj.*
- *Săptămâna viitoare **avem** examen.*

> Viitorul anterior (*voi fi cântat*) nu este tratat în această carte: vezi ultimul capitol.
