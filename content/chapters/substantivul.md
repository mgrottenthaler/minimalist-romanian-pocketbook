## Genul

Trei genuri. Testul sigur este numărătoarea, nu terminația.

| Gen | un / doi | o / două | Exemple |
|---|---|---|---|
| masculin | **un** – **doi** | — | un pom, doi pomi |
| feminin | — | **o** – **două** | o casă, două case |
| neutru | **un** – | – **două** | un tren, două trenuri |

Neutrul nu are formă proprie: e masculin la singular și feminin la plural.

## Pluralul

### Masculin

| Singular | Plural | Exemplu |
|---|---|---|
| consoană | **-i** | pom → pom**i** |
| -e | **-i** | frate → fraț**i** |
| -u | **-i** | membru → membr**i** |
| -i | **-i** | unchi → unchi |
| -ă | **-i** | tată → taț**i** |

### Feminin

| Singular | Plural | Exemplu |
|---|---|---|
| -ă | **-e** | casă → cas**e** |
| -ă | **-i** | ușă → uș**i** |
| -e | **-i** | carte → cărț**i** |
| -ea | **-ele** | stea → st**ele**, cafea → caf**ele** |
| -ie (*i* vocalic) | **-ii** | câm-pi-e → câmp**ii** |
| -ie (*i* semivocalic) | **-i** | fe-mei-e → feme**i** |

### Neutru

| Singular | Plural | Exemplu |
|---|---|---|
| consoană | **-uri** | tren → tren**uri** |
| consoană | **-e** | scaun → scaun**e** |
| -u | **-uri** | lucru → lucr**uri** |
| -u | **-e** | exemplu → exempl**e** |
| -iu | **-ii** | studiu → stud**ii** |
| -ou | **-ouri** | birou → biro**uri** |

> Nu există regulă pentru **-uri** față de **-e** la neutru, nici după consoană, nici după *-u*. Se învață cu cuvântul: *tren**uri*** dar *scaun**e***; *lucr**uri*** dar *exempl**e***.

## Alternanțe fonetice

Apar la plural și la genitiv-dativ feminin.

| | Exemplu |
|---|---|
| a → e | fată → fete, masă → mese |
| a → ă | carte → cărți, parte → părți |
| ea → e | seară → seri, creangă → crengi |
| oa → o | floare → flori, coadă → cozi |
| t → ț | student → studenți |
| d → z | brad → brazi |
| s → ș | urs → urși |
| z → j | obraz → obraji, viteaz → viteji |
| sc → șt | muscă → muște, broască → broaște |
| c → ci | sac → saci, copac → copaci |
| g → gi | fag → fagi, drag → dragi |
| l → i | copil → copii, cal → cai |

## Cazurile

Cinci cazuri, dar numai trei forme distincte: **N-Ac**, **G-D**, **V**.

| Caz | Nearticulat | Articulat hotărât |
|---|---|---|
| N-Ac sg. m. | (un) pom | pom**ul** |
| G-D sg. m. | (unui) pom | pom**ului** |
| N-Ac pl. m. | (niște) pomi | pom**ii** |
| G-D pl. m. | (unor) pomi | pom**ilor** |
| N-Ac sg. f. | (o) casă | cas**a** |
| G-D sg. f. | (unei) **case** | cas**ei** |
| N-Ac pl. f. | (niște) case | cas**ele** |
| G-D pl. f. | (unor) case | cas**elor** |

> La feminin singular, forma de **G-D nearticulat este identică cu pluralul**: *o carte* → *unei cărți*; *o floare* → *unei flori*.

### G-D cu `lui`

Numele proprii și termenii de rudenie folosiți ca nume nu primesc terminație: G-D se face cu **lui** antepus, invariabil, la ambele genuri.

| | |
|---|---|
| nume masculin | cartea **lui** Ion, îi dau **lui** Ion |
| nume feminin | cartea **lui** Maria (și: cartea Mari**ei**) |
| rudenie ca nume | mașina **lui** tata, i-am spus **lui** mama |

La feminin sunt corecte amândouă: *lui Maria* în vorbire, *Mariei* în scris îngrijit. La masculin, numai *lui Ion*.

## Vocativul

| Formă | Folosire |
|---|---|
| -e (m. sg.) | Ioan**e**! băiet**e**! frat**e**! |
| -ule (m. sg.) | băiat**ule**! prieten**ule**! |
| -o (f. sg.) | Mari**o**! fat**o**! doamn**o**! |
| -lor (pl.) | domni**lor**! copii**lor**! |

Formele în **-ule** și **-o** sunt curente; cele în **-e** sunt mai puține și fixe. La feminin, forma nemarcată (*Maria!*) e la fel de acceptabilă în vorbire.
